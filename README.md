# پلِ Novo (آیفون و کارتخوان)

این مخزن فقط برای **ساختِ** `iPhoneBridge.exe` است. کدِ اصلی در `bridge/`ِ مخزنِ خصوصیِ برنامه است و هر بار که عوض
شود همین‌جا کپی می‌شود؛ ساخت روی ماشینِ ویندوزِ گیت‌هاب انجام و با `selftest` سنجیده می‌شود.
